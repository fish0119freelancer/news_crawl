①問題

① Problem

問題與為何現在 / Problem & why now

news_crawl 每天從 30 個 RSS 抓文章，關鍵字命中約 128 篇（11/19 乾跑）；但只有每個領域前 5 篇（MAX_PER_DOMAIN=5，7 個領域，最多約 35 篇）會送 LLM 摘要並進 PDF，LINE 推 12 篇。owner 11/23：①只做 PDF 那些就好 ②改用 claude -p（帳號 A extra credit），不用 API key ③要好內容 ④之後付費會員可自訂關鍵字，後台把所有人的關鍵字聯集一起爬、一起整理，要好維護。

D212 B：改走 GitHub Actions＋Claude API：11/23 方案嘗試以 claude -p 執行，但 CI（GitHub Actions）環境無 Claude 登入憑證；經決策 D212 選擇方案 B，改採官方 Anthropic SDK 搭配 API Key，維持於 GitHub Actions 每日自動執行，並引入嚴格費用防護。

脈絡與限制（含非目標） / Context & constraints

本次範圍是把摘要 backend 改由 claude -p（Sonnet）執行，驗證格式解析、快取、重試、失敗跳過與 OpenAI fallback；非目標是本卡以外的 CI 登入、iMac launchd、LINE 實送、會員關鍵字聯集，以及與舊 gpt-4o 的同篇品質重跑。

假設全集（含被推翻者） / Hypotheses

預期在沒有 OpenAI API key 時仍可透過已登入的 Claude Code 呼叫摘要；同一 URL 第二次應命中快取而不重複呼叫；逾時應重試一次，兩次都失敗則由既有流程跳過該篇；OpenAI client 應維持可切換且採 lazy 初始化。

③決策點

③ Decisions

決策 / Decisions

成本（只算進 PDF 的篇數，每天 ≤35 篇、每月約 1,050 篇；每篇約輸入 4.5K、輸出 0.8K token；價格依官方 11/03）：

模型（claude -p）每月
Sonnet 5.5（PM 建議，品質好）約 US$18
Opus 5.5約 US$36
Haiku 5.5約 US$1

加 JD（一次性 US$30–40，之後每月 US$2–5）：Sonnet 方案首月約 US$60、之後每月約 US$22，不超過 100。
決策：①走 claude -p（帳號 A extra credit，額度約 US$200/月），不放 API key，和 JD 同一條路。②模型 Sonnet 5.5。③會員關鍵字：聯集爬一次、每篇摘要只做一次並快取，成本跟「不重複文章數」成正比，不跟會員數成正比；每領域上限改成設定值。④會員資料、付費、多租戶屬架構決策，實作前先跟 owner 討論。排佇列最後。

D212 B 架構決策（Claude API 方案）：

  • 選 Haiku 5.5：改走官方 anthropic SDK 2.8.0，選用 claude-haiku-5-5（輸入 US$0.10 / MTok、輸出 US$0.50 / MTok，來源 2026-11-24 官方 models overview；設定 effort=low，不傳 temperature 因 Haiku 5.5 拒絕非預設值）。
  • 費用保護語意：內建 CostGuard 三道防護（預設每日 40 篇上限、總花費上限 US$0.65、單篇 max_tokens 3000）。超額停止但仍出 PDF，僅在全失敗時才 exit 1。
  • 不自寫重試：依賴 Anthropic SDK 內建 max_retries=2 與指數退避處理暫態網路錯誤。
  • 每日花費估算：每日約 35 篇實際估算（每篇 2K 輸入 + 1K 輸出 ≈ US$0.0007），每日約 US$0.03，對比每日上限 US$0.65 具充足安全餘量。

⑤成效與限制

⑤ Outcome & limits

結果與限制 / Outcome & limits

有效：摘要改走 claude -p（Sonnet），不用 API key；URL hash 快取；失敗重試一次後丟例外由 main.py 既有 try/except 跳過該篇；OpenAI 保留為 SUMMARY_BACKEND=openai fallback（預設關，client 改 lazy）；MAX_PER_DOMAIN 可由 env 設定（預設 5）。

有效（Claude API）：採用官方 anthropic SDK 2.8.0，無縫切換模型 claude-haiku-5-5；內建三道費用保護（每日篇數、費用、max_tokens）；失敗大聲（拋出 FatalSummaryError 並遮蔽 headers 機敏資料）；全失敗 exit 1。

未解／風險：① GitHub Actions 沒有 Claude 登入，CI 無法跑此路徑，須改由 iMac launchd（NEWSCRAWL-IMAC 方案）或另想辦法；本卡未動 CI，請 PM 決定。② 耗時：每篇約 47 秒，35 篇循序約 27 分鐘；可平行呼叫（尚未做）。③ 額度：每篇約 15K 輸入，total_cost_usd 約 0.055／篇，35 篇／天約 US$1.9（API 等值），比卡③預估高，月額度需重算。④ 品質無法與 gpt-4o 同篇對照。⑤ RSS 內文過短時摘要資訊有限。

未解／風險（Claude API）：① 首次 CI 實跑尚待 PM 手動觸發；② 每日花費約 US$0.03 為靜態估算，需由上線首次 run 之 usage 行校正；③ tests/test_line_flex_builder.py::test_build_carousel_message_structure 在 main 上即失敗（KeyError: 'text'，非本卡引入）；④ claude -p 路徑已廢棄。
