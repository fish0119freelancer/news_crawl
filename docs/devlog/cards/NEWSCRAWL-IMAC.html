NEWSCRAWL-IMAC：每日新聞搬到 iMac launchd

① 問題

GitHub Actions 因 Ubuntu 26.04 沒有 Python 3.9 失敗（11/17 起停擺）。改在 iMac 用 launchd 每天台北 09:00 跑，同樣產 PDF、推 docs/、送 LINE。

② 流程（改後）

flowchart LR
L[launchd 09:00] --> R[run_daily.sh]
R --> K[keychain 讀 3 secrets]
K --> P[git pull]
P --> M[main.py 產 PDF]
M --> C[複製 docs/ → commit+push]
C -->|push 失敗只記 log| N[LINE 推播一次]

③ 決策點

  • secrets 只走 keychain（service=news_crawl）；token 經 stdin 給 curl，不入命令列／log。
  • push 失敗不擋 LINE（使用者先收到報告，之後手動補推）。
  • 只在 main 分支才 commit/push，避免在開發分支誤推。
  • LINE 只送一次＋當日旗標防重複（原 workflow 重複送兩次是 bug）。
  • DRY_RUN=1 在 LLM 層短路，免 key 驗證整條管線。
  • 已知坑：launchd 不會自建 log 目錄；排程在 Mac 睡眠時錯過會於喚醒補跑。

④ 證據

項目結果證明什麼

⑤ 成效與限制

有效：腳本、plist、workflow schedule 已停。未驗證：真實 launchd 觸發、git push（SSH 免密碼？）、LINE 實送——待 keychain 放入 3 個 secret。

⑥ 兩種講法

RD：launchd→run_daily.sh，keychain 取 secret，pull→main.py→docs commit/push（失敗不擋）→LINE 一次；DRY_RUN 可免 key 驗證。
一般人：每天早上 9 點改由這台 iMac 自動產生新聞報告並推給大家。
